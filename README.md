# Side Hustle Command Center

A professional, single-file web utility designed to help creators, freelancers, and entrepreneurs discover their optimal digital side hustle path, execute a structured 7-day launch plan, and instantly generate tailored AI marketing copy.

Built with clean, lightweight HTML, CSS, and modern JavaScript, this application runs entirely in the browser with zero external framework dependencies or backend requirements.

---

## ✨ Key Features

*   **1. Interactive Side Hustle Selector:** A 3-step dynamic quiz that evaluates user preferences and matches them with one of four high-leverage digital income streams.
*   **2. 7-Day Action Tracker:** A built-in milestone tracker complete with progress bars, daily goal descriptions, reflection text areas, and browser local storage persistence.
*   **3. AI Prompt Generator:** Instantly crafts professional, ready-to-use AI prompts for social media launch posts, welcome sequences, landing page hooks, and FAQ guides (fully synced with your quiz result).
*   **4. Professional UI & Dark Mode:** Features a sleek, modern design powered by Google's *Inter* font, smooth transitions, and a built-in dark/light mode toggle.
*   **5. One-Click Summary Export:** Compiles your quiz recommendations and tracker notes into a cleanly formatted report copied straight to your clipboard.

## 🛠️ Getting Started & Installation

Because this is a standalone single-file application (`index.html`), getting started takes seconds:

1. **Clone or Download** this repository to your local machine.
2. Open the `index.html` file in any modern web browser (Chrome, Firefox, Safari, Edge).
3. (Optional) Host it instantly for free using **GitHub Pages** by pointing your repository settings to the main branch.
